Cloud Infrastructure Architecture

Traffic flow and security boundaries from DNS query to edge caching and S3 origin

1

Amazon Route 53

Routes user DNS queries with latency-based or alias routing directly to CloudFront distribution.

→
2

Amazon CloudFront

Edge caches static assets across 450+ Points of Presence globally. Enforces HTTPS via AWS Certificate Manager (ACM).

→
3

Origin Access Control (OAC)

Signs requests with SigV4 so S3 only accepts traffic originating from CloudFront. Direct public S3 access is blocked.

→
4

Amazon S3 Bucket

Stores static assets (HTML, CSS, JS, images) with server-side encryption (SSE-S3 / AES-256) and versioning.

AWS Services & Technologies Used

📂

Amazon S3

Configured as a private origin. Public access is 100% blocked via S3 Block Public Access settings and strict bucket policies.

⚡

Amazon CloudFront

Global CDN delivering low latency, gzip/brotli compression, custom error pages (404/403 to index.html for SPA), and caching policies.

🌐

Amazon Route 53

Highly available and scalable cloud DNS service routing custom domains with Alias A and AAAA records to CloudFront.

🔒

AWS Certificate Manager (ACM)

Manages automated SSL/TLS certificates in us-east-1 to enable secure HTTPS communication with TLS 1.3 protocol support.

🛡

Origin Access Control (OAC)

Modern AWS standard for securing S3 origins with SigV4 authentication, replacing legacy Origin Access Identity (OAI).

⚒

CloudFormation / IaC

Infrastructure as Code templates automating repeatable, declarative infrastructure provisioning and state management.

Key Security Implementations

✔

S3 Block Public Access Enabled

All four S3 public access block flags are activated. The bucket is not accessible via public URL or direct HTTP requests.

✔

HTTPS Enforcement & Security Headers

HTTP requests are automatically redirected to HTTPS (301 Moved Permanently). Strict-Transport-Security (HSTS) headers enforced.

✔

SigV4 IAM Policy Validation

S3 bucket policy validates AWS:SourceArn matching the specific CloudFront distribution ARN.
